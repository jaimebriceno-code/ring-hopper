# Ring Hopper

A one-button arcade game. Your probe circles a young star on three orbits while rocks sweep the other way. Hop between orbits to dodge them and grab violet shards.

**Play:** open `index.html` in a browser. It is a single self-contained file (fonts load from Google Fonts), so you can drop it into any website.

## Controls

- **Space / tap / ↑** hop outward (the outer orbit wraps to the inner one)
- **↓** hop inward

## Rules

- **Gravity:** rocks on inner orbits move faster, outer ones slower.
- **Heat:** staying on the inner orbit heats the probe. Fill the bar and you're out.
- **Eclipses:** now and then the star goes dark and you only see rocks close to you.
- **Scoring:** points for time survived, close passes, and shards. Chaining shards multiplies the bonus. Your best score is saved in your browser.
